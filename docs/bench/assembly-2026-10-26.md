# Further assembly and FP process-state validation, 2026-10-26

Fresh tests ran on the physical Pico W at 200 MHz and Pico 2 W at 150 MHz,
with the standard panel console, gamma-corrected 16-pixel runtime font and
full guest/overlay allocations. The emulator contains no benchmark recognition.

| Measurement | RP2040 before | RP2040 after | RP2350 before | RP2350 after |
|---|---:|---:|---:|---:|
| Complete Unix suite | 48.37 s | 48.45 s | 55.57 s | 55.59 s |
| Double-precision Whetstone | 242.9 KWIPS | 257.1 KWIPS | 489.3 KWIPS | 491.8 KWIPS |
| Sieve, normalized ten passes | 0.840 s | 0.839 s | 0.998 s | 0.997 s |
| Program bytes | 197,620 B | 196,980 B | 199,992 B | 199,768 B |
| Code in SRAM | 49,136 B | 49,016 B | 93,004 B | 92,840 B |
| Free SRAM beyond reserved stacks/windows | 248 B | 504 B | 1,344 B | 1,628 B |

The RP2040's Whetstone throughput improves by 5.86%; RP2350 by
0.52%. These are measured results for this workload, not an
all-program multiplier. Small differences in the complete Unix suite should
be treated as essentially unchanged rather than a statistically established
speedup: each configuration ran the complete suite once. Exact samples,
phase totals and memory counts are in [the data](assembly-2026-10-26.json).

## General changes

Both chips use exact native logical 64-bit shifts for every count from 0 to
63, including overlapping source/destination pairs. This removes the RAM
mask table and compiled masking branches. RP2040 fraction multiplication
now accumulates four full unsigned 32-bit products and all 128-bit carries
in assembly; its register product kernel uses four 16-bit MULS operations.
It retains precisely the same product bits, three guard bits, DEC rounding,
exceptions and 56-bit D significand. The compiler supplies the callee-save
frame and epilogue. Standalone product-test scratch lives in the fixture.

These changes free **256 bytes on RP2040** and **284 bytes on RP2350**.
The guest remains 56/152 KB; the compressed RP2040 overlay remains 63 KB;
RP2350 retains 248 file-write blocks and 112 swap blocks. No font or audio
budget was removed. Inlining RP2350 pair helpers increased SRAM use, so that
experiment was rejected. Moving unreachable reference procedures did not
change the binary: the compiler already excludes them from SRAM.

Native helper-frequency instrumentation was kept in private builds and was
excluded from timing and publication. The clean RP2040 profile records
1,984,554 left shifts, 2,164,663 right shifts and 639,075 fraction products
during compilation and three long Whetstone runs. This identifies shared
arithmetic work rather than a special program path.

## V6 correctness discovered by the broader tests

The legacy V6 kernel compiled out its floating-point context routines;
`_savfp` was literally RTS PC. The unchanged public firmware reproduced
FPSTATE760 errors. Enabling more emulator arithmetic cannot repair that OS
configuration. The new native-built stock m45 kernel enables FPP support,
preserves all six complete accumulators and FPS in F or D mode, masks
exceptions during transfers, and clears live state on exec. A reserved FPS
bit marks a lazy save, avoiding collision with the real maintenance bit.
Both old and optimized RP2350 firmware pass the new-kernel state tests.

The RP2350 before/after table uses this **same FP-enabled kernel** on both
sides. Earlier legacy-kernel timings are retained in the raw session records;
they are not mixed into this comparison. The kernel was compiled, assembled
and linked on a physical Feather, exported with od and checked on Pico 2 W
and Feather. Existing regular files and fallback kernels remain. V6 factory
root packs change deliberately; source disks and V7 packs remain unchanged.
[Kernel details and rebuild](../v6/FP-KERNEL.md).

## Validation

- 22,528 exact RP2040 arithmetic checks and 8,192 exact RP2350 shift checks pass.
  A private arithmetic-right-shift mutant produces 518 failures.
- Both DEC JFPAA1/JFPBA0 diagnostics pass with zero errors on both chips.
- General math tests cover precision, conversions, matrices, sqrt, sin/cos,
  atan and exp/log. Process checks cover fork, blocking bidirectional pipes,
  all six accumulators/FPS, reserved operand bits, exec and signal8. The new
  V6 kernel also passes the maintenance-bit case.
- Full Unix build/assemble/archive/link, process/pipe/file, text/sort/edit,
  repeated utility/read phases pass, with checked outputs, no lost console
  input or dropped clock ticks. Each Whetstone run does 3,000 KWhetstones and
  returns X=9311/10000; each Sieve run does 100 passes and returns 1,899 primes.
- Temporary native-kernel build and helper-profile configurations are not
  production images and supply no benchmark numbers.
