# ladder.txt - the diagnostic ladder: every tape in this folder that the J-11
# emulator runs, in order, with the options each needs (tools/tape_ladder.py).
#
#   python tools/tape_ladder.py --port COMnn --plan media/diagnostics/ladder.txt
#
# Each line:  name | tape (relative to this folder) | tape2pico options | seconds
# Verdicts are tape_ladder's own: PASS = a bell, or "END PASS"/"END OF" typed;
# FAIL = "HALT at"; otherwise NO VERDICT.
#
# EXPECTED: 17 PASS, and two HALTs that are right for a J-11:
#   18_DZQKC  HALT at 014304 - it refuses to run on a large CPU, and a J-11 is one.
#   19_DEQKC  HALT at 000006 after 22 instructions - it reads 177760, which a KDJ11 does not have.
#
# THE PATCHES. 14 needs switch 200. 16_DFKAB's patches change subtests written
# for an 11/34 where the J-11 behaves differently by design (the listing expects
# the 11/34); 15646=7 is MFPT (000007), which traps on an 11/34 and is an
# instruction on the J-11. With them DFKAB types "END OF DFKAB" with no HALT.
#
