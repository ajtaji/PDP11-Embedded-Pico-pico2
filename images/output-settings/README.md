# Screen settings

Flash one UF2 matching the processor and screen. Each is 8 KB and contains
only one persistent settings sector; it leaves firmware and Unix packs alone.
All supplied files select silent audio and readable Lato-derived 14-pixel text.
`lafvin` restores the default; `none` selects USB serial only.

The same RP2350 settings apply to Pico 2 W, Pico Plus 2 W and Feather RP2350.
The wiring, other configurations and live font controls are in
[OUTPUTS.md](../../OUTPUTS.md). File hashes are in [SHA256SUMS](../SHA256SUMS).
