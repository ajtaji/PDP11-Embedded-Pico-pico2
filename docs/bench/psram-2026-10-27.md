# PSRAM sector transfers and V7 support, 27 October 2026

Both PSRAM boards run at 150 MHz with 8 MB PSRAM, 2040 KB of V7 guest memory, the original 29 disk buffers and the full 872-block swap area. The Pico Plus 2 W has 16 MB flash and the complete distribution /usr on RP03; the Feather has 8 MB flash and a selected /usr on RK1.

These are physical-board measurements of the final FP-fixed V7 kernel and general sector-copy assembly. Seconds are host elapsed time, median of three unless marked as the function-call user-time delta; concurrent shell counts and each complete Unix suite were run once. Sieve ran 100 passes per sample and is normalized to ten. Whetstone ran 3,000 KWhetstones per sample with its expected final value. No guest benchmark recognition or reduced FP precision is used.

The historical machine figures are the same original references cited above. Compilers, operating systems, storage and some benchmark versions differ. Dhrystone is a checked C1.1 algorithm port measured as a whole-process host rate, including setup/output and without the original empty-loop correction; the historical rating is an older version with its own timing method. Disk results compare RAM-backed storage with period disks. These are approximate historical comparisons, not a universal speed multiplier or a standard Dhrystone rating. No real-11/70 full-suite time has been guessed.

The complete V7 command workload changed from 76.42 to 76.44 seconds on Feather and 76.85 to 76.68 on Pico Plus 2 W: essentially unchanged. A native SRAM-only sector-transfer unit test improves from 138-164 ms to 3.5-3.7 ms for 1,024 copies, excluding PSRAM latency and controller waits. That isolated result is not a whole-emulator speedup. The assembly costs 584 bytes of SRAM code; final free SRAM is 4,204 bytes on Feather and 4,200 on Pico Plus 2 W. Guest RAM and disk capacities are retained. A 40-buffer cache trial gave no overall benefit and was rejected.

The new native V7 kernel preserves full FPS and all six D accumulators across fork and exec and masks exceptions during raw FP state copies. Both boards pass native C and Fortran double-precision compilation, awk/sed/dc/nroff, 38 concurrent child processes checking 48 KB each, raw /usr reads, FP state/math/signal checks, six independently checked concurrent shell outputs, and multi-user root login with /usr mounted automatically.

Patterned files on both RK0 and /usr were saved, then verified after a program-only reboot with the same pack nonces: 4 KB per file on Feather, 32 KB per file on Pico Plus 2 W, zero errors. Feather's factory /usr selection has only 24 free blocks (12 KB); larger working files belong on the root filesystem. Full distribution /usr needs Pico Plus 2 W. V7 retains 2040 KB guest memory because the original signed memory accounting/allocation map needs further work for a safe larger configuration.

Flash saves coalesced up to 30 line-clock ticks in an accepted PSRAM session (28 in the timed benchmark phases); these pauses are included in host elapsed times. All accepted sessions have zero lost console input. This is tested V7 core functionality, not a claim that every peripheral and application is supported.

Firmware-only updates preserve the installed guest kernel. The V7 FP fixes require the new V7 combined image or a kernel update in a backed-up filesystem. Back up saved files before replacing an OS image: the new pack nonces intentionally prevent old saved blocks from being replayed onto the changed filesystem.
